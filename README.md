# Simple Calculator in C

A menu-driven calculator project written in C. It performs addition, subtraction, multiplication, and division using user-defined functions and control structures.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Supports decimal numbers
- Checks division by zero
- Allows repeated calculations until the user exits

## Concepts used
- User-defined functions
- Function declarations and definitions
- `switch` statement
- `if-else` condition
- `do-while` loop
- Variables and input/output functions

## Files
- `main.c` - complete C source code
- `sample_output.txt` - example program run

## How to compile and run

Using GCC:

```bash
gcc main.c -o calculator
./calculator
```

On Windows:

```bash
gcc main.c -o calculator.exe
calculator.exe
```

## Example
Choose `1` for addition, enter `12.5` and `7.5`, and the result will be `20.00`.
